Quire: the note, glass and ink

Every state of the note, in light and dark. The spec is docs/quire-design.md. Add ?play=1 to this URL for the clickable prototype, ?screen=<id> for one screen, &theme=dark, &size=g14 (1920×1200 dp, rendered at 1.5× for the G14's 2880×1800), &wall=bloom|strata|tide for another wallpaper behind the glass, and &glass=0 for the platform's blur-off fallback. All values on screen are sample data.
