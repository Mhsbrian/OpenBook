# Security policy

## Supported versions

OpenBook is a developer preview. Fixes go into the next preview only. Previews are `userdebug` builds signed with
Android's public test keys: use them on a laptop that holds nothing you need.

## Reporting a vulnerability

Report it privately through this repository's **Security → Report a vulnerability** page (GitHub private
vulnerability reporting). Please don't open a public issue for a vulnerability. We aim to answer within seven days.

Include the release or commit, the laptop model, what you did and what happened.

## Scope

The OpenBook images, the installer, the update tooling and the scripts in this repository. For a flaw in a
third-party component (AOSP, Linux, Mesa, NVIDIA's open kernel modules), please report it upstream as well.
